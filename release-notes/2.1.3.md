# Aurora Client 1.21.11-2.1.3

For Minecraft 1.21.11 with Fabric.

- Added Discord Rich Presence support across Aurora Client and Aurora Launcher. The mod reports menu, singleplayer, and multiplayer activity to the launcher, which manages Discord presence and privacy preferences.
- Added an authenticated local activity bridge with bounded updates and failure handling that keeps gameplay unaffected if the optional integration is unavailable.

Install `aurora-2.1.3.jar` in your Minecraft `mods` folder. Discord Rich Presence integration requires launching through a compatible Aurora Launcher.
