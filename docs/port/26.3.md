# Port to Minecraft 26.3

Branch `port/26.3`, stacked on PR #11 (`port/26.2`). This is roadmap step 4's newest-version port. Publishing remains a separate owner-reviewed release step; the feature freeze remains in place.

The [Fabric porting notes](https://fabricmc.net/2026/09/15/263.html) describe the SDL and RenderPearl changes. Minecraft has supplied native Vulkan since 26.2, and Sodium supports it. VulkanMod is superseded for these versions.

## Input and saved settings

- Keyboard bindings use SDL physical scancodes. `KeybindMigrator` translates legacy GLFW integers by their vanilla persistent key names, independently for the config and each imported profile. The profile-scoped `keybindVersion` marker prevents a second conversion. All 18 integer key fields and the Keystrokes extra-key list are covered. Missing fields retain current defaults; Aurora's unbound value stays `-1`. Unsupported F25 and invalid legacy values become unbound with a warning.
- Both code defaults and the packaged factory defaults use the new codes. The effective default key names and feature switches are preserved. Vanilla options continue to store stable key names.
- Pointer routing follows SDL's left=1, middle=2, right=3 numbering, including delegated widget events and click counters. Text fields retain vanilla's native text-input focus notifications.
- Frame deadlines use SDL's monotonic clock. Reflex sleeps use bounded `parkNanos` waits and leave queued SDL events for vanilla to dispatch. The pacing algorithms and automatic latency budget are retained.

## Rendering

- GPU resources, pipeline types and mixin descriptors follow RenderPearl's APIs. GPU query values are scaled by the device timestamp period and translated using its calibration offset. Automatic GPU timing remains active on both native backends.
- World overlays draw at Fabric's `END_MAIN`, where an explicit native pass can safely open. The earlier translucent-feature callback now executes inside an existing pass.
- Glass uses Minecraft's compiled pipelines and combined image-sampler bindings. Shader inputs/outputs have explicit locations. Glass frame resets run at `Minecraft.renderFrame`, covering loading and disconnect frames that bypass `runTick`; pooled resources still retire at the next frame.
- First-person item hooks use extracted player/hand state and native item submission. Flat GUI item sprites read `ItemQuads` through a guarded accessor. There are 73 mixins.
- Alternative Glint changes only glint composition in the combined item/entity shaders, retaining lighting, overlays, fog, vertex layouts and all OIT phases. Separate shield/trim glint retains its native depth and destination alpha. The two adapted vanilla shader files are credited in `THIRD_PARTY_NOTICES.md`.
- Hurt armor uses native armor pipelines with the overlay sampler enabled. Combined armor glint, per-face lighting, paletted trim UVs and decal depth remain intact. Turning the corresponding switches off restores vanilla behavior.
- Better Hitreg's port edits follow relocated render APIs, changed callback signatures and vanilla's new invulnerability accessors; its timing logic is unchanged.

## Verification (2026-11-11)

- `gradlew build`: 655 tests discovered, 654 passed, one skipped. The static mixin target checker reports zero problems, including optional targets. New migration tests cover the complete legacy key-name fixture, field coverage, config/profile independence, idempotence and invalid inputs. Pipeline tests verify native state and OIT preservation, feature gates, armor lighting and decal depth.
- The separate-glint GPU regression test now compiles the shipped shader without adding missing extensions on its behalf. It reproduced the trimmed-armor shader failure before the fix and passes afterward.
- OpenGL and native Vulkan boots into a disposable upgraded copy of the world apply all 73 mixins. No test upgrades the owner's live world. The temporary probe is excluded from the mod jar and matrix runs.
- Inspected Dark-theme grid/list, detail screens, search and title/menu settings at 854x480 and 1598x892, using live SQUARE/19% and factory ROUND/33% glass. Labels retain their alignment. Native text focus, text entry, Escape unfocus, primary clicks and right-click detail navigation work. A zoom rebind to Z persists in config and vanilla options through relaunch; config/profile legacy migration runs independently.
- Enchanted held sword and translucent glass (including the OIT path), shield status, world hitbox/block outline, hurt armor and enchanted gold-trimmed armor were exercised. Vulkan screenshots compare trim tinting on/off and Alternative Glint on/off. Returning from the world to no-world menu glass passes the layering guard after moving the reset hook.
- The OpenGL baseline and performance stack exceed the unchanged release overhead budget. Vulkan baseline/stack and OpenGL Sodium + Iris pass. Publication remains blocked by this gate; the port is submitted for review as a draft.
- Factory-default overhead and compatibility results are recorded in [MOD_MATRIX.md](../MOD_MATRIX.md). The matrix pins stable Sodium 0.9.2 with Iris 1.11.7, matching Iris's dependency, plus the current 26.3 performance stack.

Evidence is retained locally under ignored `build/port-26.3/`; it is not packaged. These are Windows 11 / RX 9070 XT dev-client checks. Multiplayer, shader packs, a production launcher, physical held-key FreeLook/zoom, damage tilt, every armor-trim pattern and every screen/mod combination remain unverified. Owner merge and production publication are separate steps.

The owner's live config/options match all 46 backed-up files byte-for-byte after these checks.
